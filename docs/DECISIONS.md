# Architecture decisions

## ADR-001: Independent, new application
BioFlow begins as a new software project from a family-care need. Its published demonstration uses independently invented patients, dates, measurements and laboratories, with no copied patient records.

## ADR-002: Canonical originals
Private Cloudflare R2 preserves each PDF byte-for-byte. SHA-256 is recorded; downloaded originals are streams of the stored object, never regenerated by a model. Hash verification does not certify medical authenticity.

## ADR-003: Authentication before personal data
The initial public routes return fictitious data only. Real document routes deny access until Auth0 and storage are configured. Authorization is performed on the backend on every request.

## ADR-004: Clinical review and provenance
Cloud-hosted Gemma will propose structured extraction; MongoDB Atlas will store source references and human-approved fields. No automatic diagnosis, silent corrections or implicit grants.
